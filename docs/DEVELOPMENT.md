# Ветка dev — 1.5-dev

Разработка ведётся отдельно от стабильной ветки `master`. Тег `1.5-dev` не создаёт GitHub Release; debug APK загружается в артефакты CI ветки `dev`. При отправке тега дополнительно собирается оптимизированный APK с подписью приложения, доступный в артефакте `sirin-music-1.5-dev`. GitHub Release не публикуется.

## Память и хранилище

Обложки используют ограниченный LRU-кеш: 64 МиБ на диске и до 24 МиБ в оперативной памяти (не более 10% доступной приложению heap). При уведомлении Android о нехватке памяти или уходе интерфейса в фон кеш в RAM очищается. Изображения, которые ещё отображаются на экране, могут оставаться в памяти до закрытия экрана.

В настройках показывается текущий размер дискового кеша и доступна кнопка очистки. Она удаляет кеш обложек в RAM и на диске; данные подключения, избранное на сервере и воспроизведение не затрагиваются. Отображаемые обложки могут кешироваться повторно при следующих запросах. Музыка на диск не сохраняется.

Размер «Приложение» в Android не равен размеру APK и не является размером кеша. Для release включены R8 и удаление неиспользуемых ресурсов. Размер установленных файлов и подготовленного Android кода зависит от устройства. Debug-сборки не уменьшаются R8.

## Оформление и большие экраны

Десять готовых палитр и свой цвет: оттенок, насыщенность, яркость или HEX. [MaterialKolor Color Utilities](https://github.com/jordond/MaterialKolor) строит полную светлую/тёмную схему с контрастным текстом. При включённых цветах из обоев используется системная схема; для выбора своего цвета этот переключатель нужно выключить.

На широких окнах используется навигационная панель сбоку, адаптивные сетки избранного, артистов, альбомов и плейлистов. В плеере от 840 dp управление и очередь располагаются в двух колонках с независимой прокруткой. Настройки, вход, профиль и тексты песен ограничены по ширине для удобного чтения.
