# Сообщения об уязвимостях

Не публикуй API-токены, ключи подписи, частные адреса серверов или логи с личными данными в открытых Issues.

Если нашёл уязвимость, используй приватное сообщение об уязвимости в GitHub, когда эта возможность включена в репозитории. Если она недоступна, сначала создай Issue с просьбой предоставить приватный канал связи, без деталей эксплуатации и секретов.

Клиент авторизуется на сервере, адрес которого ты настроил. Для подключения через недоверенную сеть используй HTTPS. Ключи подписи APK должны храниться в приватном хранилище и секретах GitHub Actions, а не в репозитории.

Обновления загружаются отдельным HTTP-клиентом из стабильных релизов этого репозитория. Перед передачей APK системному установщику проверяются размер, SHA-256 и совпадение сертификатов подписи с установленным приложением. API-токен musik в запросы GitHub не передаётся.
